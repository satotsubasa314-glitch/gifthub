# GiftHub（仮）

贈る前に、相手の本音を知る。贈ったあと、どうだったかが返ってくる。
ギフトアプリのプロトタイプです。

## 構成

HTML 1枚のみ。フレームワーク・ビルド不要。

```
deploy/
  index.html    アプリ本体
```

## 公開

Vercel に接続しています。`main` に push すると自動で公開されます。

- Framework Preset: Other
- Root Directory: `deploy`
- Build Command: なし

## ローカルで動かす

```
cd deploy
python -m http.server 8900
```

ブラウザで `http://localhost:8900/` を開く。

## 主な機能

- 中身を隠したまま ◯× で相手の好みを聞く
- 贈ったあと「もう使った？」で事実を聞く
- 気持ち → 贈ったもの → どうだったか を記録に残す
- ギフトーク AI（ギフトのことなら何でも聞ける）
- 受け取る側はアプリ不要（URL を開くだけ）

## 状態

プロトタイプです。ログインと AI はモックで、本物のサービスにはつないでいません。
差しかえ箇所はソース内にコメントで明記しています。
